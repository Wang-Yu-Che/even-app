# even-app

## 内置眼镜预览

右侧任务页面在主窗口的 Canvas 内渲染，不启动外部模拟器进程。
Go 将成功发送到眼镜的文本、容器参数和 BMP 图标直接同步给预览组件，
因此布局、边框和图标复用真机数据。当前预览范围是任务状态页面，
不包含手动图片、列表或 Dashboard。它不是眼镜画面回传，Canvas 字体栅格化
与眼镜 LVGL 字体可能略有差异，最终显示仍以真机为准。

需要核对官方 LVGL 效果时，可在预览工具栏点击“打开原生模拟器”。该操作才会
启动随应用打包的官方模拟器进程；应用启动及内置预览不会自动启动它。

开发时先在 `frontend` 运行 `npm install` 和 `npm run build`。

验证：

```sh
go test ./...
```
