# 地球纹理来源

`earth-source.jpg` 来自 NASA Goddard Space Flight Center Scientific Visualization Studio 的
[Equirectangular Projected Earth for “LARGEST”](https://svs.gsfc.nasa.gov/3615/)，
原始文件为 `earth_noClouds.0330.jpg`（2048×1024）。NASA/GSFC 的 Blue Marble Next Generation
数据由 Reto Stöckli 与 NASA Earth Observatory 提供。运行时转换为眼镜的灰度画面；选择无云版本是为了在低分辨率下保留清楚的海岸线。
